# Bold Caption Bot

A Telegram bot that automatically converts channel file captions into Unicode Bold.

## Features
- Auto detects channel posts
- Converts captions to Unicode Bold
- Reposts the same file with a bold caption
- Render-ready

## Deploy
1. Fork/upload this repo to GitHub.
2. Connect it to Render.
3. Add these environment variables:
   - API_ID
   - API_HASH
   - BOT_TOKEN
   - LOG_CHANNEL
   - OWNER_ID
4. Deploy.

## Install locally

```bash
pip install -r requirements.txt
python bot.py
